WORKSHOP 4 พ.ย. 2569 · ช่วงที่ 2 จากหน้าจอจริง

วิธีสร้าง VCN
ด้วย VCN Wizard ทีละขั้น

เดินตามภาพจริง 7 ขั้นตอน สร้างเครือข่ายให้มี Public IPv4 พร้อมก่อนสร้างเครื่อง ตามหลัก "Network ก่อน Instance"

ใช้เวลาไม่ถึง 2 นาทีCIDR 10.0.0.0/16ได้ครบ VCN + Subnet + IG + NAT

ภาพทั้งหมดในชุดนี้ปิดข้อมูลเฉพาะตัวแล้ว: ชื่อ tenancy, OCID ของ VCN และ ID ในข้อความ error ของ Console

1/7

ขั้นที่ 1 — เปิดเมนู Networking → Virtual cloud networks

  • กดเมนู ☰ แล้วเลือก Networking → Virtual cloud networks (เปิดคั่นกลางระหว่างสร้างเครื่องอยู่ก็ได้แบบในภาพ แล้วค่อยกลับไปสร้างเครื่องต่อ)
  • ทำเครือข่ายให้เสร็จก่อนสร้างเครื่องเสมอ เพราะถ้าไปสร้าง subnet ใหม่ในหน้าสร้างเครื่อง ตัวเลือก Assign public IPv4 จะถูกล็อก
2/7

ขั้นที่ 2 — เปิด VCN Wizard จากหน้า Virtual Cloud Networks

  • กดปุ่ม Actions → Start VCN Wizard เพื่อเริ่มตัวช่วยสร้างเครือข่าย
  • หมายเหตุจากภาพจริง: ข้อความ Couldn't load the data / The required information to complete authentication... เป็นอาการชั่วคราวของ Console (เซสชันหลุด) ให้ refresh หน้าเว็บหรือ Sign in ใหม่ ไม่ได้แปลว่าบัญชีไม่มีสิทธิ์ (ค่า Session ID และ OPC-Request-ID ในภาพถูกปิดไว้)
3/7

ขั้นที่ 3 — เลือก Create VCN with Internet Connectivity

  • เลือกการ์ดฝั่งซ้าย Create VCN with Internet Connectivity แล้วกดปุ่ม Start VCN Wizard มุมขวาล่าง
  • ตัวเลือกนี้สร้างให้ครบในชุดเดียว: VCN, public subnet, private subnet, Internet gateway (IG), NAT gateway (NAT) และ Service gateway (SG)
  • แถบด้านบนของภาพยืนยันสถานะบัญชี: Free Tier account — You are in a Free Trial
4/7

ขั้นที่ 4 — ตั้งค่า VCN (Configuration)

  • VCN name ตั้งชื่อจำง่าย เช่น my-first-vcn และ Compartment เลือก root ของบัญชีตัวเอง
  • ส่วน Configure VCN ใช้ค่ามาตรฐานของ wizard ได้เลย: VCN CIDR 10.0.0.0/16, public subnet 10.0.0.0/24, private subnet 10.0.1.0/24 แล้วกด Next
5/7

ขั้นที่ 5 — ตรวจทานแล้วกด Create (Review and create)

  • ตรวจสรุปให้ตรง: Name = my-first-vcn, IPv4 CIDR block = 10.0.0.0/16, DNS label = myfirstvcn
  • กล่อง Warning: Resource availability checked successfully เป็นข้อความปกติ แปลว่าตรวจแล้วสร้างได้ ไม่ใช่ข้อผิดพลาด
  • กดปุ่ม Create มุมขวาล่าง
6/7

ขั้นที่ 6 — รอระบบสร้างทรัพยากรให้ครบ

  • ระบบสร้างทีละรายการจนขึ้น 100% Done: Create VCN, Create subnets (public และ private), Create internet gateway, NAT gateway และที่เหลือ ใช้เวลาไม่ถึงนาที
  • เสร็จแล้วกดปุ่ม View VCN เพื่อดูรายละเอียด
7/7

ขั้นที่ 7 — VCN พร้อมใช้งาน (Available)

  • หน้ารายละเอียดต้องขึ้นชื่อ my-first-vcn พร้อมป้ายสถานะ Available และ IPv4 CIDR Block = 10.0.0.0/16
  • ขั้นต่อไป: กลับไปสร้าง Compute Instance แล้วเลือก VCN นี้ + public subnet และติ๊ก Assign public IPv4 จะได้เครื่องที่มี Public IP ตั้งแต่เกิด
  • ค่า OCID ในภาพถูกแทนด้วย <VCN_OCID> และชื่อ tenancy ถูกแทนด้วย your-tenancy-name เพื่อความปลอดภัย

เช็กลิสต์หลังสร้าง VCN เสร็จ

  • VCN สถานะ Available และ CIDR = 10.0.0.0/16
  • มี public subnet 10.0.0.0/24 และ private subnet 10.0.1.0/24
  • ขั้นต่อไป: สร้าง A1 Instance โดยเลือก VCN นี้ใน สไลด์หลักของเวิร์กช็อป
  • ยังไม่มีบัญชี Oracle? เริ่มจาก สไลด์วิธีสมัคร Free Tier ก่อน

หมายเหตุ: ภาพต้นฉบับชุดนี้มีชื่อ tenancy จริงและ OCID จริงของ VCN ให้ใช้เฉพาะภาพที่ปิดข้อมูลแล้วในสไลด์ชุดนี้ในการสอนและเผยแพร่
