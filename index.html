Wizard สร้างให้ครบ — เหลือแค่เช็กพอร์ต

ช่วงที่ 2 · Network เพื่อ IPv4

จุดที่เคยติด: Assign Public IPv4 ถูกล็อก 🔒

❌ อาการที่เจอ

ในหน้าสร้าง Instance ถ้ายังเลือก “Create new public subnet” อยู่ ตัวเลือก Assign a public IPv4 address จะถูกล็อก กดติ๊กไม่ได้ — สร้างเครื่องไปก็ไม่มี Public IP

✅ วิธีแก้ที่ถูกต้อง

ย้อนไปสร้าง VCN ด้วย Wizard ให้เสร็จก่อน (สไลด์ 06–07) แล้วตอนสร้าง Instance ให้เลือก Public Subnet ที่มีอยู่แล้ว — ช่อง Assign Public IPv4 จะปลดล็อกทันที

🧭 จำสั้น ๆ

Subnet สร้างในหน้า Instance = IPv4 ล็อก · Subnet สร้างจาก Wizard มาก่อน = IPv4 ติ๊กได้ — นี่คือเหตุผลที่คอร์สนี้บังคับทำช่วงที่ 2 ก่อนช่วงที่ 3

พิสูจน์ว่าใช้ได้จริง: SSH เข้าเครื่อง

เปิด Terminal แล้วใช้คำสั่งตาม OS ที่เลือก — แทน <Public-IP> ด้วยเลข Public IP จากหน้า Instance Details

Ubuntu — ผู้ใช้ ubuntu

# เข้าได้สำเร็จจะเห็น prompt ของเครื่อง เช่น ubuntu@a1-free:~$ ← แบบนี้แปลว่า IPv4 + SSH ผ่านครบ 🎉

ช่วงที่ 3 · สร้าง Instance

ไม่มี Public IP / SSH ไม่เข้า — เช็ก 4 จุดตามลำดับ

อย่าเดาสุ่ม ไล่จากนอกเข้าในตามนี้ ส่วนใหญ่จบที่ข้อใดข้อหนึ่ง

  1. 1
    อยู่ Public Subnet หรือเปล่า?
    เปิด Instance Details เช็ก Subnet — ถ้าเป็น Private Subnet จะไม่มี Public IP ตั้งแต่ต้น
  2. 2
    Route ถูกต้องไหม?
    Route Table ของ Public Subnet ต้องมี 0.0.0.0/0 → Internet Gateway
  3. 3
    Security List เปิดพอร์ต 22 หรือยัง?
    Ingress Rule ต้องอนุญาต 0.0.0.0/0 · TCP · 22
  4. 4
    Firewall ใน OS เปิดพอร์ตนั้นหรือเปล่า?
    กฎใน Cloud ผ่านแล้ว แต่ Firewall ภายในตัว OS ยังบล็อกได้ — เช็กเป็นจุดสุดท้าย

เช็กเพิ่มตอน SSH: ใช้ Private Key ไฟล์ที่โหลดตอนสร้างเครื่อง · ชื่อผู้ใช้ตรงกับ OS (opc = Oracle Linux, ubuntu = Ubuntu) · พิมพ์ Public IP ไม่ผิด

Tips พิเศษ · อ่านก่อนตัดสินใจ

อีกวิธีให้ได้ A1 ง่ายขึ้น: อัปเกรดเป็น Pay As You Go

บัญชีแบบ PAYG มีโอกาสสร้าง A1 สำเร็จ / ได้ Capacity สูงกว่า Free Tier ล้วน ๆ — แต่ “อัปเกรด” ไม่ได้แปลว่า “ใช้เกินโควตาฟรีได้ฟรี” อ่านกล่องเตือนด้านล่างให้จบก่อนตัดสินใจ

ทางที่ 1 · ปลอดภัยสุด

อยู่ Free Tier เดิม

  • ไม่มีค่าใช้จ่าย — ไม่มีอะไรให้ตัดบัตรเกินโควตา
  • สร้าง A1 Always Free ได้ตามปกติแบบที่ทำในคลาสนี้
  • ข้อเสีย: Capacity หายาก โดยเฉพาะ Singapore ช่วงคนแย่งกัน
ทางที่ 2 · โอกาสได้เครื่องสูงกว่า

อัปเกรดเป็น PAYG

  • โอกาสสร้าง A1 สำเร็จสูงกว่า เข้าถึง Capacity ได้มากกว่า
  • ทรัพยากรในโควตา Always Free ยังใช้ฟรีเหมือนเดิม
  • ข้อควรระวัง: เกินโควตา = คิดเงินจริง ตัดบัตรจริง ต้องคุมเองตลอด

🚨 PAYG ฟรีเฉพาะ “ในโควตา + Shape ที่ Eligible” เท่านั้น

  • ฟรีเฉพาะ A1 รวม ไม่เกิน 2 OCPU / 12 GB RAM และ Boot/Block Volume รวม ไม่เกิน 200 GB
  • ต้องเป็น Resource ที่ขึ้นว่า Always Free-eligible เท่านั้น — เลือก Shape อื่นที่ไม่ Eligible, สร้างเกินโควตา หรือเปิด Resource เสริมที่คิดเงิน ระบบคิดค่าใช้จ่ายจริงและตัดบัตรได้ทันที

🛡️ Guardrail สำหรับคนเลือก PAYG — ทำครบทุกข้อ

  • ก่อนกด Create ทุกครั้ง เช็กว่า Shape เป็น VM.Standard.A1.Flex + มีป้าย Always Free-eligible
  • อย่าสร้างเครื่องเกินโควตา 2 OCPU / 12 GB RAM / Volume 200 GB (นับรวมทุกเครื่อง)
  • ตั้ง Budget Alert แจ้งเตือนอีเมล และหมั่นตรวจ Cost Analysis ว่าค่าใช้จ่ายยังเป็น 0
  • ลบ Resource ที่ไม่ใช้ ทิ้งทันที อย่าปล่อยเครื่อง/Volume ค้าง
  • ช่วงแรกหลังอัปเกรด เช็กบิลบ่อย ๆ จนมั่นใจว่าไม่มีรายการคิดเงินโผล่มา

Tips · เมื่อสร้างเครื่องไม่ผ่าน

เจอ “Out of capacity” ที่ Singapore ทำยังไง?

A1 ฟรีที่ Singapore เต็มบ่อย เพราะทั้งภูมิภาคแย่งโควตาเดียวกัน — ไม่ใช่เราทำผิดขั้นตอน ลองตามนี้ก่อนยอมแพ้

🔁 วิธีลองใหม่ให้ได้เครื่อง

  • เปลี่ยน Availability Domain แล้วกดสร้างใหม่
  • ลองใหม่ช่วงคนน้อย — เช้ามืด / นอกช่วงพีค โอกาสว่างสูงกว่า

ของที่ ไม่มีใน Repo มาตรฐาน ของ OL9: ripgrep กับ ffmpeg

Hermes ใช้ ripgrep ค้นหาไฟล์/ข้อความ และ ffmpeg แปลงไฟล์เสียง — สองตัวนี้ไม่ได้อยู่ใน Repo มาตรฐานของ Oracle Linux 9 ตรง ๆ จัดการตามนี้

ripgrep — เปิด EPEL ก่อน แล้วลงได้เลย

sudo dnf install -y oracle-epel-release-el9 sudo dnf install -y ripgrep

แพ็กเกจ oracle-epel-release-el9 คือตัวเปิดคลัง EPEL อย่างเป็นทางการสำหรับ OL9 — เปิดแล้ว ripgrep ถึงจะโผล่มาให้ติดตั้ง

ffmpeg — ข้ามได้ ไม่ต้องฝืนลง

  • ไม่มีทั้งใน Repo มาตรฐานและ EPEL ของ OL9 (อยู่ค่าย RPM Fusion) — คลาสนี้ไม่ต้องเพิ่ม Repo นอกเพิ่ม
  • ใช้เฉพาะ แปลงเสียง TTS เป็น Opus สำหรับส่ง voice ใน Telegram เท่านั้น ไม่กระทบการใช้งานหลัก ของ Hermes
  • ตัวติดตั้ง Hermes จะ พยายามลง ffmpeg ให้เองผ่าน dnf อยู่แล้ว — ถ้าไม่ได้ มันจะเตือนแล้ว ติดตั้งต่อ ไม่หยุดกลางทาง
